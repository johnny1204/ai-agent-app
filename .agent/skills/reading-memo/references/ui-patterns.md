# UI コンポーネント設計

## ページ構成

| パス | 内容 | 公開範囲 |
|------|------|----------|
| `/` | 本棚一覧（グリッド表示） | Public |
| `/books/[id]` | 書籍詳細 + メモ表示 | Public（公開メモのみ） |
| `/admin` | 管理ダッシュボード | Private |
| `/admin/books/new` | 書籍登録 | Private |
| `/admin/books/[id]/edit` | 書籍編集 + メモ入力 | Private |

## コンポーネント一覧

### BookCard

書籍1冊分のカード。グリッド内での表示単位。

```tsx
type BookCardProps = {
  id: number;
  title: string;
  author: string;
  coverUrl?: string;
  status: 'unread' | 'reading' | 'finished' | 'practicing';
  tags: string[];
};
```

表示要素:
- 表紙画像（なければタイトルのプレースホルダー）
- 書名・著者名
- ステータスバッジ
- タグチップ（最大3つ、残りは `+N` 表示）

### BookGrid

BookCardを並べるレスポンシブグリッド。

```css
.book-grid {
  display: grid;
  gap: 1.5rem;
  grid-template-columns: repeat(auto-fill, minmax(220px, 1fr));
}
```

### StatusBadge

ステータスに応じた色分けバッジ。

| ステータス | カラー |
|-----------|--------|
| 積読 | `bg-gray-100 text-gray-600` |
| 読書中 | `bg-blue-100 text-blue-700` |
| 読了 | `bg-green-100 text-green-700` |
| 実践中 | `bg-amber-100 text-amber-700` |

### MemoEditor（管理画面用）

3タブ切り替えのメモ入力エリア。

```
┌─────────────────────────────────────────┐
│ [著者の主張]  [自分の洞察]  [具体アクション] │
├─────────────────────────────────────────┤
│                                         │
│  テキストエリア                           │
│                                         │
├─────────────────────────────────────────┤
│ □ 公開する                    [保存]      │
└─────────────────────────────────────────┘
```

### MemoDisplay（公開ビュー用）

メモをカテゴリ別に構造化表示。

```
📖 著者の主張
  ─ メモ内容...

💡 自分の洞察
  ─ メモ内容...

🎯 具体アクション
  ─ メモ内容...
```

### TagFilter

タグによる絞り込みバー。チップ形式で選択可能。

```
[全て] [AI] [Web] [DB] [設計] [テスト] ...
```
